## همسریابی شرعی ایرانیان\n\nسایت استاتیک فارسی برای GitHub Pages. پیش از انتشار، نام کاربری/مخزن را در sitemap.xml و robots.txt جایگزین کنید و اطلاعات تماس واقعی را در index.html درج کنید. صفحات شهرها نمونه اولیه هستند و باید با محتوای محلی واقعی، مفید و غیرتکراری تکمیل شوند. این بسته فعلاً ۳۰ شهر نمونه دارد؛ فهرست همه شهرها و شهرستان‌ها باید از داده معتبر تکمیل شود.\n
